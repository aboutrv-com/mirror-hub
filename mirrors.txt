# Mirror configuration — one repo per line, "#" starts a comment.
#
# Format:   <source-url>   <destination owner/name>   [fallback-url]
#
# - source-url   : upstream repo to pull from (read-only). Tried first.
# - destination  : GitHub repo to push into; created automatically if missing.
#                  Must live under an owner your GitHub App is installed on.
# - fallback-url : OPTIONAL. Tried if the source-url fetch keeps failing
#                  (e.g. sourceware.org HTTP 429 rate-limiting). A different
#                  protocol/host for the SAME repo — commonly a git:// URL,
#                  whose daemon (port 9418) doesn't share the HTTPS limiter.
#
# Each URL is retried with exponential backoff before falling through to the
# next; if all URLs fail, the mirror is skipped and retried on the next run.
#
# Add a mirror = add a line. Remove a mirror = delete its line
# (the destination repo is left untouched; delete it manually if you want).
