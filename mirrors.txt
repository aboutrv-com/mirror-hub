# Mirror configuration — one repo per line, "#" starts a comment.
#
# Format:   <source-git-url>   <destination owner/name>
#
# - source-git-url : upstream repo to pull from (read-only, https)
# - destination    : GitHub repo to push into; created automatically if missing.
#                    Must live under an owner your GitHub App is installed on.
#
# Add a mirror = add a line. Remove a mirror = delete its line
# (the destination repo is left untouched; delete it manually if you want).
